# 迪卡侬中国 · Digital 部门门户（原型）

**解压后，双击 `portal/index.html` 就能打开。**
不用安装任何东西、不用启动服务器、不用联网。

建议用 **Chrome 或 Edge** 打开——页面把字体和图标都打包在本地了，需要现代浏览器才能完整显示；用很旧的浏览器可能字体回退、观感不同。

## 能点哪里

- **顶部一级导航**：首页 · 今日 Hub / 信息中心 / 监控运营 / 知识中心 / 工作台
- **分区内的标签页**：
  - 信息中心 → 公告与决议 / 产品 Release / 项目动态
  - 知识中心 → 最佳实践 / 设计规范 / FAQ
  - 工作台 → 工具导航 / 组织速查 / 需求提交
- **全局搜索**：点顶栏搜索框，或直接按 `/` 键唤起
- **Agent for Digital**：右上角打开右侧对话抽屉（演示为脚本化回复）
- **通知**：右上角铃铛
- **反馈**：右上角咖啡杯图标，打开「内部门户建设反馈」表单
- **工具分组直达**：工作台 →「工具导航」，按分组进入会直接定位到该分组

## 里面的数据是真的吗？

**不是。** 全部为示意数据，页脚也标注了「本原型所有数据均为示意数据 · 非真实运行值」。人名、指标、公告内容都是围绕迪卡侬中国数字化场景构造的样例。

## 这份原型要回答什么？

它不是一套可以上线的系统，而是用来**评审两件事**：信息架构是否按「用户任务」分区合理、以及视觉方向（品牌色、排版、信息密度、图形语言）是否符合预期。请带着「找东西快不快、看得懂不懂」来看它。
