# 调研底稿 02 · decathlon.com.cn 实测视觉规范

> 采集方式：headless Chrome（CDP）打开生产站点，读取全量元素的 computed style 与字体加载记录。
> 采集时间：2026-09-17。**所有色值均为站点真实运行值，非推测、非公开报道转述。**

---

## 一、字体系统

```
html / body font-family: Roboto, Decathlon
使用分布：Roboto, Decathlon (1208 处) / Decathlon (114 处) / Roboto (38 处)
已加载：Roboto(400, loaded)、Decathlon(400, loaded)
```

**实际 @font-face 声明（站点源码原样）**

```css
@font-face { font-family: Roboto; font-display: swap; font-weight: 400;
  src: url("/static/d-assets/fonts/DECATHLON-Medium.ttf") format("truetype"); }
@font-face { font-family: Decathlon; font-display: swap; font-weight: 400;
  src: url("/static/d-assets/fonts/DECATHLON-Medium.ttf") format("truetype"); }
```

**关键判断**：站点把自有字体 `DECATHLON-Medium.ttf` 同时注册为 `Roboto` 和 `Decathlon` 两个字体族——也就是说页面名义上"用 Roboto"，实际渲染是迪卡侬自有字体。

**对本项目的可执行结论**：
- 自有无衬线字体（Decathlon Sans / DECATHLON-Medium）**不可对外分发**，内部原型不应内嵌该字体文件。
- 采用 **Google Roboto**（Apache-2.0，可自由内嵌）作为首选字体族——这既是站点名义声明的字体，也避免了字体版权问题。
- 若团队持有内部授权字体，只需把 `"Decathlon Sans"` 插入字体栈首位，其余不变。

- 配色骨架为：**白底 + 靛蓝强调 + 深墨色文本 + 浅灰面 + 黄色点缀**。

## 四、渲染观察（截图判读）

**品牌特征（可迁移）**
1. 顶栏白底、横向留白充足、导航项轻量。
2. 搜索框为**浅灰胶囊形填充**。
3. 主按钮为**胶囊形实心品牌蓝**。
4. 卡片为**浅灰块 + 图标 + 短标签**的磁贴网格。
5. 区块标题下方带**小面积强调色标记**（黄）。
6. 大量留白，网格整齐。

**营销语气特征（**不**迁移到内部工具）**
1. 加粗斜体大标题。
2. 全宽照片 Hero。
3. 约 100px 的大号浅灰磁贴。
4. 深色图片叠加白字的卡片。

## 五、对齐策略（给设计系统与原型阶段的交接单）

**采纳**
- 主色切换为 `#3643BA`；配套深色阶由其派生。
- 墨色 `#000F17` 作为标题与强文本；`#616161` 次级、`#B3B7B9` 三级。
- 面层用 `#F5F4F5`，边框 `#D9DDE1`。
- 黄 `#FFCD4E` 保留为**次级强调**，仅用于小面积标记（置顶、里程碑、NEW）。
- 警示红沿用 `#E3262F`。
- 字体族采用 **Roboto**（可自由内嵌）+ 中文回退栈；数字与版本号用等宽。
- **胶囊圆角用于按钮、标签、搜索框**——这是品牌签名特征，成本低、识别度高。

**拒绝**
- 加粗斜体大标题、照片 Hero、大号浅灰磁贴、图片叠字卡片——这些是营销语气，进入内部工具会挤占信息密度。
- 紫色 `#8126A3` 仅作站点分类标记，不纳入系统色板。

**科技感的落点（用户明确要求）**
1. **字体**：Roboto 正文字族 + 等宽数字（版本号 / ID / 指标值），精密感来自字体的分工而非装饰。
2. **符号**：统一的 1.5px 线性图标体系，尺寸 16 / 20 两档；品牌符号仅在页头与空态使用。
3. **配色**：以 `#000F17` 深墨色顶栏建立识别度，`#3643BA` 作强调蓝，浅灰面承载内容——深色结构色 + 明亮强调色的组合即是科技感的来源，无需霓虹与渐变。
